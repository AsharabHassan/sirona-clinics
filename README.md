# PBSerum VELURIA for Clinics

A conversion-focused Sirona Aesthetics campaign page for UK clinics. The page
combines:

- a clinic-personalised landing experience;
- a real VELURIA before-and-after case study from Aesthetics Central;
- a main CTA that opens the consented camera/upload experience immediately;
- an instant branded patient preview and clinic-growth report;
- an optional live, non-diagnostic AI skin visualisation;
- a clinic growth report comparing product-only promotion with the connected
  VELURIA + AI patient journey;
- a transparent clinic scenario planner;
- repeated booking paths to a free 20-minute VELURIA Clinic Growth Map; and
- a secondary private-walkthrough lead form connected to GoHighLevel.

Built with Next.js 15, React 19, TypeScript and Tailwind CSS.

## Verified personalised outreach links

Clinic pages render only from source-backed records in
`data/clinic-profiles.json`. Unknown slugs return a 404 and arbitrary clinic
names in the query string are ignored:

```text
https://your-domain.example/clinic/approved-clinic-slug
```

Recipient links use an encrypted, expiring token generated by the private
outreach controller. The token contains no readable personal information.

Follow-up messages can deep-link to a specific proof stage while retaining the
clinic personalisation:

```text
# Email 1: verified clinic overview
https://your-domain.example/r/{OPAQUE_TOKEN}/email-1

# Email 2: VELURIA AI growth funnel and patient application
https://your-domain.example/r/{OPAQUE_TOKEN}/email-2

# Email 3: doctor-facing before-and-after application
https://your-domain.example/r/{OPAQUE_TOKEN}/email-3

# Email 4: contextual AI Sales Brain and consultation handoff
https://your-domain.example/r/{OPAQUE_TOKEN}/email-4
```

## Environment

See `.env.local.example` for the complete template.

| Variable | Purpose |
| --- | --- |
| `ANTHROPIC_API_KEY` | Cosmetic visible-skin analysis for the optional live preview. |
| `OPENAI_API_KEY` | AI-generated visualisation for the optional live preview. |
| `GHL_WEBHOOK_URL` | Sirona GoHighLevel webhook used by the private-walkthrough form. |
| `NEXT_PUBLIC_CALENDAR_URL` | Sirona's free 20-minute online consultation calendar. |
| `NEXT_PUBLIC_META_PIXEL_ID` | Optional campaign attribution. |
| `OUTREACH_TOKEN_SECRET` | Encrypts expiring recipient attribution tokens. |
| `GHL_OUTREACH_EVENT_WEBHOOK_URL` | Dedicated Sirona workflow webhook for campaign events. |

## Outreach controller

The controller is paused by default and never transmits messages. It prepares
approval packets and releases approved rows for manual email and LinkedIn
execution only after all identity, suppression, location and UK-time gates pass.

```bash
npm run outreach:init
npm run outreach:validate
npm run outreach:status
npm run outreach:readiness
npm run outreach:research
npm run outreach:learn
```

See `OUTREACH_IMPLEMENTATION.md` for the evidence file, approval workflow and
GoHighLevel configuration.

## Production safeguards

- The Aesthetics Central case study can be explored without an AI request.
- A visitor must explicitly consent before adding a photo.
- Camera and photo-upload controls stay disabled until consent is recorded.
- Live AI routes enforce request-size checks and lightweight per-visitor limits.
- The UI describes outputs as illustrative, cosmetic and non-diagnostic.
- The scenario planner exposes its assumptions and does not present a forecast.

For a multi-instance production deployment, replace the in-memory AI route
limiter with a shared rate-limit store and complete a documented privacy review
of every image-processing provider before sending campaign traffic.
